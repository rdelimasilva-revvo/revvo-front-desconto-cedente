# Tela de Detalhes do Cliente - Risco Sacado

## Descrição
A tela de **Detalhes do Cliente** fornece uma visão completa e detalhada das operações de antecipação de um cliente específico, seguindo o formato padrão do sistema com indicadores macro, dashboard e tabela de contas a pagar.

## Funcionalidades

### 📊 Indicadores Macro (Cliente Específico)
- **Total Disponível Cliente**: Valor total disponível para antecipação do cliente
- **Total em Aprovação Cliente**: Valores do cliente em processo de aprovação
- **Total Antecipado Cliente**: Valores já antecipados pelo cliente
- Cada indicador mostra a variação percentual em relação ao mês anterior

### 📈 Dashboard
- **Gráfico de Valores a Receber por Mês**: Visualização de 13 meses dos valores a receber do cliente
- **Gráfico de Valores Antecipados por Mês**: Visualização de 13 meses dos valores antecipados do cliente
- Ambos os gráficos são responsivos e incluem tooltips informativos

### 📋 Tabela de Contas a Pagar
Tabela completa baseada na estrutura do banco de dados `accounts_payable`:

#### Colunas da Tabela
- **Nº da NF**: Número da nota fiscal (`invoice_number`)
- **Vencimento**: Data de vencimento da nota fiscal (`due_date`)
- **Valor Bruto**: Valor total da nota fiscal (`gross_value`)
- **Nº Duplicata**: Número da duplicata/parcela (`duplicate_number`)
- **Valor da Parcela**: Valor da parcela específica (`parcel_value`)
- **Vencimento Parcela**: Data de vencimento da parcela (`parcel_due_date`)
- **Status**: Status atual da conta (`status`)

#### Status Disponíveis
- **Pago**: Conta quitada (verde)
- **Pendente**: Aguardando pagamento (amarelo)
- **Vencido**: Conta em atraso (vermelho)
- **Antecipado**: Valor antecipado (azul)

### 🔍 Filtros e Ações

#### Filtros
- **Filtro por Status**: Permite filtrar contas por status específico
- **Todos os Status**: Opção para visualizar todas as contas

#### Ações
- **Exportar**: Funcionalidade para exportar dados para Excel/PDF
- **Filtros Avançados**: Botão para acessar filtros mais complexos
- **Voltar**: Navegação de volta para a lista de clientes

## Integração com Banco de Dados

### Tabela `accounts_payable`
```sql
create table public.accounts_payable (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  supplier text null,
  invoice_number double precision null,
  due_date timestamp with time zone null,
  duplicate_number double precision null,
  parcel_value double precision null,
  status text null,
  constraint accounts_payable_pkey primary key (id)
);
```

### Hook Personalizado (`useAccountsPayable`)
- **Fetch de Dados**: Carrega contas a pagar do cliente via Supabase
- **Atualização de Status**: Permite alterar status das contas
- **Adição de Contas**: Funcionalidade para adicionar novas contas
- **Gerenciamento de Estado**: Loading, erro e dados
- **Cache Local**: Otimização de performance

## Navegação
1. Acesse **Gestor de dívidas** > **Risco Sacado**
2. Clique em "Ver Detalhes" em qualquer card de cliente
3. A tela de detalhes será exibida com os dados específicos do cliente
4. Use o botão "Voltar" para retornar à lista principal

## Responsividade
- **Desktop**: Layout em grid com 3 colunas para indicadores, 2 para dashboard
- **Tablet**: Grid adaptativo com 2 colunas
- **Mobile**: Layout em coluna única

## Estados da Aplicação
- **Loading**: Indicador visual durante carregamento dos dados
- **Erro**: Mensagem de erro em caso de falha na comunicação
- **Vazio**: Mensagem quando não há dados para exibir
- **Sucesso**: Exibição normal dos dados

## Funcionalidades Futuras

- **Histórico de Alterações**: Rastreamento de mudanças de status
- **Relatórios Customizados**: Geração de relatórios específicos
- **Notificações**: Alertas para vencimentos próximos
- **Bulk Actions**: Ações em lote para múltiplas contas
